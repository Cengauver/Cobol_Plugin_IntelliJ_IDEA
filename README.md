# Cobol Plugin

### Just a plugin for a "niche?" and old programming language named Cobol.

### The supported extension is .cbl but you can change it to your needs by configuring the plugin.xml file and CobolFileType Class.

### You can change the color scheme any time through : Settings | Editor | Color Scheme | Cobol

### Build by using the gradle command "build" or "buildPlugin".

### You should use single quotes instead of double quotes for string literals

### Feel free to give any feedback.

### IMPORTANT: This plugin only works for a minimal part of cobol. See the demo text in Settings | Editor | Color Scheme | Cobol.
